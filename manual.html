明月秋青智脑

你在酒馆和角色聊天，它在后台默默帮你 记、理、用。 所有的角色记忆、剧情时间线、关系变化，它都打理好了，你只管聊。

记

每轮对话后自动总结刚才发生了什么、出现了什么新物品和新地点。聊久了还会做一次"大总结"，把整段剧情整理成清晰的时间线，写入每个角色的记忆档案。

理

分析角色之间的关系变化、每个角色的性格随着剧情怎么演变、你的互动风格有什么特点。还会把故事里出现过的地点和物品串成一个知识网，也能从世界书里批量提取角色名字、从源头减少认错人。

用

每次 AI 要回复你的时候，智脑从记忆库里挑出最相关的内容，悄悄塞进上下文。所以角色聊着聊着就会"记得"你们之前一起经历过的事。

1 打开酒馆 → 顶部菜单"扩展管理" → "酒馆助手" → "脚本" → "新建脚本" → "全局脚本"
2 在输入框中粘贴下方地址
3 点击确认。稍等几秒，出现紫色的悬浮窗即安装成功
→ import 'https://cdn.jsdelivr.net/gh/sillytavner-jpg/zhino-script@v5.2.9/dist/index.js'

五分钟配置

装好之后，按顺序做这四件事。之后只管聊。

第一步：适配预设务必先做

智脑往上下文里塞内容，靠的是你预设里的"槽位"。不同作者的预设结构千差万别，手动加条目不现实——这一步帮你一键搞定。

1 打开智脑面板 → 总览 → 智脑设置 → 点 「预设适配…」
2 弹窗里点 「适配当前预设」。智脑会读取你正在用的预设，把该插的条目插到合适位置，生成一个「原名（智脑适配）」的新预设——原预设一个字符都不动
3 到酒馆的预设列表里，把当前预设切换到「（智脑适配）」那一份，适配才真正生效
4 回到同一个弹窗的下半部分，填上你预设里的输出标签（见下表）

② 输出标签 — 告诉智脑你的预设怎么写

智脑要从 AI 回复里切出思维链 / 正文 / 时间三块。填上你预设里用的标签名，智脑就能读懂；留空 = 用内置默认。

字段示例填写对应读取
思维链标签thinking_left<thinking_left>…</thinking_left>
正文标签content<content>正文</content>
时间标签time<time>时间</time>
  • 填了是「追加」不是替换——内置默认照样生效（已兼容星光预设那套 thinking_left / right / love / director，以及老预设的 [metacognition] 写法）。
  • 同一类可填多个（换行 / 逗号 / 顿号分隔），正文里出现其中任意一个，智脑就会读它；只写标签名，尖括号不用写。
  • 设置存在全局里，换聊天、换角色卡都保留。弹窗底部会实时显示「当前生效」的三个标签。
用「智脑-Z」预设的，这一步直接跳过——它已经内置了全部智脑槽位，无需适配。

第二步：配置 API

先在总览界面选好模式。打开 总览 → 智脑设置 → 破限词，按你用的模型二选一：「老模型」适用于 Gemini 3.1、Gemini 3 Flash、DeepSeek 系列；「3.7 / 8F」适用于 Gemini 3.7 / 3.8 Flash。切换后下一次分析即刻生效。

然后打开 设置 → 网络与 API → 管理 API，添加你的 API。智脑的后台任务需要调用模型来生成总结和记忆，推荐按以下分配：

任务类型推荐模型
大总结 / 角色记忆Gemini 3.1 Pro / DeepSeek V4.1 / Gemini 3.7 · 3.8 Flash
小总结 / 世界推进Gemini 3 Flash / DeepSeek V4.1 / Gemini 3.7 · 3.8 Flash
其余全部Gemini 3.1 Pro / DeepSeek V4.1 / Gemini 3.7 · 3.8 Flash
调度模式：在管理 API 页面的"调度模式"中，如果你的渠道支持同时 5 个并发调用，或者你给不同功能分别配了不同渠道的 API，建议开启并发模式——多个任务同时跑，体验更流畅。否则选排队模式，任务按顺序逐个执行。

第三步：开启语义召回可选

设置 → 网络与 API → 开启"语义召回"。推荐使用硅基流动（SiliconFlow）的免费向量模型 BAAI/bge-m3：

  • 去 siliconflow.cn 注册，在 API 密钥页面复制你的 Key
  • 回到智脑召回设置，粘贴 Key；模型填 BAAI/bge-m3，维度选 1024
  • 地址默认即可（https://api.siliconflow.cn/v1/embeddings）
  • 填好后点一下测试连接，显示成功就配置完了

语义召回能让记忆匹配从"关键词"升级为"含义理解"——比如能认出"打架"和"起冲突"是同一件事。长篇多角色时效果显著，短篇可以先不开。

第四步：填写你的用户人设

1 打开智脑面板，点击 玩家 标签，进入 用户人设
2 点击 新建，用几句话描述你自己——性格、说话风格、习惯都行，不用写很长
3 点击 保存并分析，AI 自动生成你的互动画像。分析完成后角色就能更懂你的风格
完成后：先正常聊几十轮，再打开智脑面板看看。角色记忆、剧情时间线都已经自动生成了。之后只需根据自己的习惯微调设置即可。

基础功能

四个核心模块，默认全开、全自动。你不用管，聊就完了。

小总结每轮 · 自动

智脑的心跳，也是所有记忆的地基。

  • 每轮对话后扫描一遍：什么时间、在哪、谁在场、发生了什么、出现了什么新物品和新地点。
  • 搭车维护知识图谱：同一趟 API 顺带输出图谱变更（新增/更新/删除地点与物品），不额外花钱。
  • 是一切的底座：大总结、知识图谱、记忆召回都建立在它之上——所以它默认每轮都跑，不要关。

大总结每 10 轮 · 自动

把流水账整理成"编年史"。

  • 积累到一定轮数后，把这期间的剧情整理成完整时间线，并为每个角色生成记忆档案（就是下面那条"角色记忆"）。
  • 分版本管理（v1 / v2 / v3…）。总览里对最新版本有三个操作：撤回（回退到指定版本）、恢复、重新总结。
  • 撤回后，该版本覆盖楼层内的角色记忆会一并还原到上一版本。
  • 触发间隔可以在设置里调（默认 10 轮）。

角色记忆大总结时生成

每个角色的第一人称记忆档案，分两层管理。

两层结构

  • 核心记忆（永久）：决定角色本质的关键事件和关系，不会被自动删除，只有你手动降级为"近期"后才会被替换。每条带时间戳和版本号。
  • 近期记忆（自动更替）：最近 N 次大总结范围内的互动记录，每次新总结后被覆盖，保留最近 3 个版本。

生成与维护

  • AI 以角色第一人称撰写（"我……"），每条 15-40 字，每角色每次生成 4-8 条（可调）。
  • 反极端化：被要求不写"永远""绝对""彻底"，改用"当前""倾向""最近"等柔性词。
  • 追忆面板：人物志 → 角色 → 追忆，按大总结版本分组展示全部历史，可手动编辑、升降级（核心 ↔ 近期）、逐条删除。

玩家人设默认开启

让角色"认识"屏幕外的你。

  • 在 玩家 → 用户人设 里写几句话描述自己，点「保存并分析」，AI 会生成一份互动画像。
  • 画像会注入上下文，让角色对你的性格、说话方式、行为模式有稳定的认知（而不是每轮靠猜）。
  • 支持多个角色卡共用，也可为不同角色卡建不同的人设；可随时重新分析。

进阶功能

四个"加料"模块，让角色更活、世界更真。需要主动开启，按需取用。

默认状态一览： 这四个模块 全部默认关闭，去 设置 → 常规设置 → 自动分析 里按需打开。
梦呓（每 10 轮）、动态人设（每 2 轮）较轻量，开了就能跑； 世界推进、剧情导演更吃 API、也更依赖前置数据，建议先玩熟基础功能再开。

梦呓 — 行为翻译手册每 10 轮 · 默认关

"AIRP 就像一场梦，梦中的呓语。"梦呓不是性格总结，而是一份"行为翻译手册"——告诉 AI 当你做了某个动作时，应该理解成什么、不要误解成什么。

分析内容

  • 基础信息：姓名/性别/年龄/身份，从对话中能推断的部分
  • 性格调色盘：底色、主色调、当前压力值——AI 用来理解你当下的情绪基调
  • 肢体接触习惯：对不同角色的接触方式、频率、触发条件
  • 说话方式：句式特征、语气偏好、典型回应模式
  • 情绪表达：每种情绪 → 你的外在表现 → AI 禁止误读成什么
  • 按角色分组：你对每个角色的独特互动模式
  • Roll 偏好：你倾向于哪种叙事风格

运作机制

  • 触发：每 10 轮 AI 回复后独立触发，不依赖大总结
  • 分析来源：聊天中你所有的用户输入记录 + 你填写的用户人设
  • 注入位置：用户消息中、AI 正文生成之前——让 AI 在写回复前先"读懂你"
  • 注入策略：按当前在场角色条件注入，不在场的角色交互模式会被跳过
  • 可编辑：面板中所有字段可手动修改，支持撤回/恢复
  • 防污染：NSFW 梦呓单独存储，只在标记为 NSFW 的对话中注入

动态人设 — 角色会变每 2 轮 · 默认关

角色的性格不再是一成不变的初始设定——经历会留下痕迹。

  • 每 2 轮扫描一次剧情，捕捉角色情绪状态、关系态度、行为倾向的细微变化。
  • 以角色第一人称写出当下状态。比如一个温柔的角色的经历背叛后，可能逐渐变得多疑、说话带刺——智脑会把这种演变写进去。
  • 同样是反极端化的：用"最近""当前""似乎"这类柔性词，避免性格突变或走向极端。
  • 与"角色档案"（固定设定）配合：档案是底色，动态人设是此刻的样子。
  • 面板里可查看历史版本、手动删除某一版；注入开关在 设置 → 动态人设注入。

世界推进 — 不在场角色的独立生命每 2 轮 · 默认关

防止故事世界"冻结"——主角在 A 地推进剧情时，B 地的角色也有自己的生活。

前置条件：世界推进必须与以下模块同时开启才能正常工作：① 小总结（提供图谱数据和在场角色判定）；② 角色记忆（提供角色的既往事实和态度）；③ 知识图谱自动（提供角色位置、物品、连通路径）。此外，推演前需在「世界」面板中手动选择绑定的世界书条目——条目中应包含不在场角色的设定信息，否则 AI 推演缺乏角色依据。

🔄 三步联动闭环

第一步 · 输入 — 知识图谱 + 角色记忆双源取料

智脑自动筛选不在场角色（当前楼层不在场），综合态度、上次互动距今轮数、手动指定等维度打分排序，最多取 2 个。对每个候选角色：

  • 从知识图谱取：当前位置 + 所在地全部物品 + 一跳连通地点路径 + 到主角所在地的最短路线
  • 从角色记忆取：最近 10 条核心/近期记忆，确保推演行动与既往事实、态度、目标连续
  • 可选从世界书取：你在面板中选择绑定的世界书条目作为额外参考

第二步 · 推演 — AI 精推行动

AI 在思维链中逐角色推演：确认时间切片 → 检查地点/物品/路径 → 参考记忆确保连续 → 判断行动方向。每个角色输出一条第一人称近期记忆（30-80 字），可选附带轻微结果和自然入场引导：

  • level 0：不暴露（不强行引入角色）
  • level 1：痕迹/物品/传闻（路过痕迹、遗留物品、旁人提及）
  • level 2：口信/书信/通讯（可自然插入的远程互动）
  • level 3：短暂本人入场（场景允许时角色短暂出现）

第三步 · 消费 — 三路输出

  • → 注入 AI 上下文：无入场引导的角色动态，作为"场外角色动态"注入；有入场引导的插在梦呓位置上方
  • → 合并进角色记忆：下一次大总结时，把覆盖楼层范围内的推演记忆按剧情时间排序合并进角色记忆档案
  • → 辅助小总结：最近一条未消费的推演记录作为材料发给小总结，提供"中心角色"和"中心地点"的判定依据

触发时机：世界推进不在 AI 回复后立即执行，而是标记 pending → 等你下一次发消息时才后台推演。避免与 AI 正文生成抢 API、阻塞聊天体验。默认每 2 轮触发一次。

剧情导演 — 给故事一条主线每 5 轮校对 · 默认关

怕剧情跑偏？先和 AI 定个大纲，它会定期帮你把故事拉回正轨。

  • 入口：智脑面板 → 世界 → 剧情导演。先选篇幅（短篇 / 中篇 / 长篇）→ 和 AI 讨论生成大纲 → 点 「激活大纲」才开始生效。
  • 自动校对：激活后每 5 轮校对一次剧情是否偏离大纲，给出方向提示（"推进阶段"）。
  • 防剧透模式：开启后，校对只提示"该往哪个方向走"，不会把大纲里的后续情节提前抖出来。
  • 引导是建议不是命令——不会硬拽剧情，只给 AI 一个方向参考。
  • 随时可以 「放弃大纲」；面板里能看到大纲的全部阶段与当前进度。

常见问题

先打开总览，确认智脑能看到你的楼层（状态仪表盘里会显示"当前楼层"）。然后用批量总结消化历史：勾上「事件总结 + 角色记忆总结」，每批 40 层左右比较合适；想补知识图谱就再单独勾「图谱总结」，一次 20 层左右。总结完成后，去设置 → 网络与 API → 召回设置，点「为旧数据生成向量」，等进度条跑完就行。小总结不用补。

先检查 API 设置——有可能是 API 配置的问题，确认 Key 和地址都没填错。如果不是 API 的问题，去设置 → 网络与 API，点API 监听器的「查看日志」（它始终开启），再触发一次分析，看智脑发出去的请求和 API 回来的回复。如果回复内容正常、也没有截断，带上你的截图和 API 回复找常陆茉子反馈。旁边还有一个「代码日志」，可以看智脑自己的运行日志。

有两条路。① 连聊天一起搬：智脑数据全存在酒馆的聊天记录里（角色记忆、时间线、图谱、世界推进、梦呓、动态人设等），导出聊天文件、在新电脑导入即可，数据自动恢复。② 只想把记忆搬到另一个聊天：设置 → 数据管理 → 「本地数据 · 导出」，勾选要带走的 12 个分组导出成文件；到目标聊天里点「导入」→ 「继承到新聊天」——它会自动重置楼层相关的游标（否则总结 / 梦呓都不再触发），而记忆内容原样保留。

批量总结本身不再自动重试，失败会暂停并弹出重试浮层：点「重试」继续、点「取消重试」结束本次批量（结束后面板上会出现「▶ 继续总结」，可以接着跑）。如果反复失败，把每批的楼层数量调小一点再试。「⏹ 停止总结」现在点下去会立刻生效。

重 roll 单层：完全没问题，什么都不用管。智脑会自动重跑该楼层的小总结并替换旧记录，图谱和角色位置同步更新。

多层退回重 roll：请注意以下限制：

  • 已开启知识图谱：图谱最多保留 6 张快照，只支持五轮内退回。超出五轮的旧图谱已被淘汰，无法恢复。
  • 未开启知识图谱：可以退回多层之前，不受图谱快照限制。
  • 大总结：在总览处可手动撤回，回退到指定版本。撤回后覆盖楼层内的角色记忆会被还原到上一版本。
  • 动态人设：不会自动回退，须在面板中手动删除对应版本。
  • 世界推进：退回楼层范围内的推演记录需手动逐条删除。

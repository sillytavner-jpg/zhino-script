## 本次重点

**A5.3.9** —— 智脑改用**流式请求**（本版核心）。

非流式请求要等全部生成完才收到响应（大总结实测 31 秒），中间浏览器收不到任何字节，
代理 / 网关 / 中转站的静默超时容易在这段真空期掐断连接 → `Failed to fetch`。
酒馆主对话用的是流式，所以从没这个问题。

现在所有分析请求改走流式：

1. **连接持续有数据** → 不会被静默超时掐断（就是上面那个报错的解药）
2. **实时生成进度** —— 总览的状态仪表盘上方会显示
   `● 大总结 生成中… 1,234 字 · 12.3s`
3. **失败就重试，不猜格式** —— 流式失败会如实报错并自动重试（默认 3 次），
   仍失败则提示去「API 监听」看现场；不做自动降级、不替渠道猜格式
4. **截断检测** —— 连接中途被掐断时会明确报「疑似被截断」，不再把半截内容当完整结果录入
5. **新增开关** —— 设置 → 网络与 API → 请求方式（流式 / 非流式，供不支持流式的渠道手动切换）

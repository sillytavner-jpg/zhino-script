## 本次重点

**A5.3.6** —— 修复：重 roll / 删楼层后隐藏楼层全部失效 + 删楼后楼层游标悬空。

隐藏数据其实一直是好的（248 份聊天备份里隐藏数量从未下降），丢的是**页面上的外观** ——
重 roll / 删楼会重建消息区，而隐藏外观没被重新贴上（所以刷新页面就能恢复）。
现在隐藏改走酒馆原生 `/hide`、`/unhide`，并加了自愈：楼层一变就自动重贴。

同一病灶的另一面是**删楼后游标悬空**：智脑的 8 个楼层游标 + 一堆以楼层号为键的记录
（捕获正文、覆盖区间、图谱版本…）都会指着不存在的楼层，
表现为大总结 / 小总结 / 梦呓 / 动态人设 / 世界推进**不再触发**。
现在会跟着楼层前移一起迁移。

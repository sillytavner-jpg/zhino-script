## 本次重点

**A5.3.7** —— 修复角色名死锁（改名后角色「消失」，想重建又提示「已存在」）+ 全角括号名字归一化 + 破限词改为按分析类型配置。

玩家反馈的那个死锁拆开看是三处叠出来的：改名叫旧名**降级成别名**（列表只显示主名，所以看着「消失」）、
新建查重**把别名也算已存在**（所以建不了）、而手动删别名**没有同步到角色注册表**（所以救不回来）。
现在三个口子都补上了，并新增「从别名拆出为独立角色」—— 合并有路，终于也有拆分的门。

名字归一化同时修掉一个更危险的隐患：名字**整个被括号包住**时（如 `【清月】`）
会被归一化成**空名字**，而空名字之间会互相判重。

**破限词**从「总览」搬进了「设置 → API 库管理 → 分析类型分配」：
每个分析类型一行两个按钮（老模型 / 3.7·3.8F），点哪个就是哪个；
顶部有总开关可一键全切。老存档自动沿用原来的全局设置，行为不变。
